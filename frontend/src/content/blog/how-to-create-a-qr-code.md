QR codes feel recent, but they have quietly become the default bridge between the physical and digital worlds. A menu, a poster, a business card, a product label — all of them now carry a little square of black-and-white modules that phone cameras read in an instant. If you have been postponing learning how to create one, this guide is for you.

## What a QR code actually is

A QR (Quick Response) code is a two-dimensional barcode invented in 1994 for tracking auto parts. Unlike a traditional barcode, it stores data both horizontally and vertically, so it packs hundreds of times more information. Your phone's camera reads it almost instantly because the code embeds three finder patterns (the big squares in the corners) that tell the reader where the code is, plus timing patterns that help it resolve the grid even when photographed at an angle.

## What can you encode?

Almost any short text, but in practice five payload types cover nearly every use:

- **URLs** — the most common. Point the code at a website, a menu, or a booking page.
- **Wi-Fi credentials** — encode your network name and password so guests connect without typing.
- **Contact details** — a vCard payload that drops a name and phone number into a phone book.
- **Plain text** — a note, an address, or a coupon code.
- **Email addresses** — code that opens a pre-addressed (even pre-written) draft.

## Error correction: the thing nobody teaches

QR codes survive damage and partial obstruction thanks to Reed-Solomon error correction. The four levels — L, M, Q, H — trade capacity for resilience. Level L corrects about 7% of the code, level H around 30%. Most scanners read level M (15%) comfortably, which is why it is the sensible default for everyday codes. If your code will be printed on fabric or curved packaging, consider Q or H — but remember that higher correction means a denser, chunkier square.

## Make codes that actually scan

- **Respect the quiet zone.** Always leave a margin of blank space (roughly 4 modules, or a quarter of an inch) around the code. Cropping your code flush against other artwork is the #1 scanning killer.
- **Keep the contrast strong.** Dark modules on a light background. Avoid low-contrast colors and, especially, printing black-on-black or white-on-white.
- **Size matters.** On print, a common failure is making the code too small. A general rule: 2 cm (about 0.8 inch) minimum for codes shown at arm's length.
- **Test before you commit.** Print a test copy and scan it on two different phones, including at arm's length and at an angle.

## Dynamic versus static codes

Services sell "dynamic QR codes" — codes that let you change the destination later and track scans. Nice, but they make you dependent on that service: cancel it and the code dies. A static code, like the ones you make with a generator, is encoded with the destination baked in forever. It cannot be edited and cannot be tracked, but it also cannot be taken away from you. For permanent prints, static is usually the better bargain.

## The takeaway

Creating a QR code is a two-minute job that requires no account, no money, and — with the right tool — no uploading of your data. Encode your URL, respect the quiet zone, and test before printing. Ten thousand menu designers have been doing it for years; now you have the playbook too.
